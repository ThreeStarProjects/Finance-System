Tools

Bulk operations and data maintenance.
Bulk paste processor
After pasting historical rows into a Transactions_<FY> tab, run this to: fill Group from Category, fill Party_ID from Party_Name (smart-matched), re-apply dropdowns, refresh directories. Safe to re-run.

    


    

      
Deduplicate parties

      
Finds duplicate vendors/customers in M_Party (smart-matched by name), keeps the lowest-numbered ID, retargets transactions, deletes the extras. Safe to re-run.

      
      

    


    

      
Merge two parties manually

      
Pick a source (the duplicate to remove) and a target (the one to keep). Every bill, payment, invoice and transaction pointing at the source is retargeted to the target, then the source is deleted from M_Party. Same type only — vendor→vendor, customer→customer.

      

        
        
      

      

        

          

        

          

      

      
      

    


    

      
Refresh project dropdowns

      
Re-applies the Project-name data-validation dropdown on Bills / Invoices / Payments / Bill_Payments / every Transactions_<FY> sheet, using the current M_Project list. This runs automatically when you add / update projects via the Masters tab — use this button only if you edited M_Project directly in the sheet, or if the auto-run didn't take.

      
      

    


    

      
Rebuild directories

      
Recomputes Customer_Directory and Vendor_Directory from current transaction data. Run after manual sheet edits.

      
      

    


    

      
Re-apply formatting

      
Re-applies brand colours, zebra striping, currency format on all data sheets.

      
      

    


    

      
Find Owner-Funds "Company" rows

      

        Lists every Fund In/Out (Owner) transfer whose On_Behalf_Of is "Company", "Owner", or blank — these show up as a fake "Company" owner on the dashboard's Owner Funds card. Fix each by opening the sheet+row and typing the actual owner name (Reeta, Girish, etc.).
      

      
      

    


    

      
Deep tally — reconcile dashboard numbers

      

        Reads every sheet the dashboard uses (Transactions, Bills, Bill_Payments) and dumps a full breakdown: totals by class, by status, by FY, plus gap flags. Use this to figure out why a KPI doesn't match a sheet-side sum.
      

      

        
        
      

      
Whitespace is stripped, so "2025 -26" also works.
